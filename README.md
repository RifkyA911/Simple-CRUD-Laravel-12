<h1 align="center">Simple CRUD — Laravel 12</h1>
<p align="center"><em>A basic CRUD application built with Laravel 12</em></p>

---

## English

A simple CRUD (Create, Read, Update, Delete) application built with Laravel 12. Perfect as a learning base or project starter template.

### Features
- Full CRUD operations
- Input validation
- Data pagination
- Blade templating

### Installation
```
git clone https://github.com/RifkyA911/Simple-CRUD-Laravel-12.git
cd Simple-CRUD-Laravel-12
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate
php artisan serve
```

### Tech Stack
- Backend: Laravel 12
- Database: MySQL / PostgreSQL
- Frontend: Blade + Bootstrap
